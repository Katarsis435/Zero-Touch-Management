# Zero-Touch-Management
Задачи. Запустить сервер, провести эксперимент и выполнить измерения:
* Время ответа модели
* Время работы всего скрипта
* Загрузку CPU и RAM
* Правильность ответа
* Наличие галлюцинаций

##Ход работы:
Краткое описание эксперимента
1. Установка и запуск модели
Был установлен и запущен локальный LLM-сервер Ollama. Загружена модель phi3:mini (команда ollama pull phi3:mini), адаптированная для работы на оборудовании ограниченной мощности.

2. Разработка промптов
Для каждого из трёх агентов разработаны индивидуальные системные промпты, определяющие их роль и формат ответа:
- Agent1_Translator — сетевой архитектор: переводит интент в технические требования
- Agent2_Writer — инженер Cisco: генерирует команды CLI по требованиям
- Agent3_Verifier — эксперт по безопасности: проверяет конфигурацию

3. Проведение эксперимента
Разработан Python-скрипт, который:
Последовательно вызывает трёх агентов через API Ollama
Передаёт каждому свой промпт и контекст
Замеряет время выполнения, потребление RAM, загрузку CPU и количество токенов

Параметры:
Модель: phi3:mini
Температура: 0 (для воспроизводимости)
Лимит токенов: 500 на агента
Таймаут: 600 секунд
Тестовые интенты (3 шт.):
OSPF с аутентификацией MD5, отключение Telnet, включение SSH
Настройка VLAN 100/200, назначение портов, запрет ICMP
Настройка DHCP-сервера с диапазоном адресов
Прогоны: каждый интент запускался 3 раза => 27 запусков агентов

4. Сбор и анализ результатов
Результаты сохранены в форматах CSV и JSON, содержащих:
Время ответа каждого агента
Изменение RAM и CPU
Количество входных/выходных токенов
Сгенерированный вывод и статус выполнения
